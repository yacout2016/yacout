# GRIFFINE — الاختبارات التلقائية

الفولدر ده للمطورين فقط، ولا يُرفع على الاستضافة. ملف الإصدار المضغوط (zip) لا يحتوي عليه.

## المتطلبات
- Node.js 18 أو أحدث، و PHP 8 (مع mysqli)، و MariaDB أو MySQL
- متصفح Chromium. غيّر مساره بالمتغير `GT_CHROME` (الافتراضي `/opt/pw-browsers/chromium`)

## التجهيز (مرة واحدة)
1. أنشئ قاعدة اختبار فيها نسخة من الجداول الأساسية، ثم شغّل عليها `ALL_SCHEMA_UPDATES.sql`.
   ```
   CREATE DATABASE gtest; CREATE USER gt@localhost IDENTIFIED BY 'gt'; GRANT ALL ON gtest.* TO gt@localhost;
   ```
2. أنشئ في القاعدة حساب أدمن للاختبار (الافتراضي `top72026@gmail.com` / `Test12345`). يمكنك تغييرهما بالمتغيرين `GT_ADMIN` و `GT_ADMIN_PASS`. اختبار 12 يحتاج أيضًا حساب موظف (`yacout2021@gmail.com`) وحساب عميل (`paytest@example.com`)، وكلمات سرهما في `GT_STAFF_PASS` و `GT_CUSTOMER_PASS`.
3. انسخ ملفات الموقع إلى فولدر اختبار، وضع فيه `tests/griffine_config.test.php` باسم `griffine_config.php`. لا تستخدم ملف الموقع الحقيقي أبدًا.
4. `cd tests && npm install`

## التشغيل
```
node mocks/paymob-mock.js &      # محاكي Paymob + واتساب (منفذ 8097)
node mocks/market-mock.js &      # محاكي أسعار TradingView (منفذ 8098) - /set?sym=COMI&price=77
php -S 127.0.0.1:8099 -t <فولدر-الاختبار> -d sendmail_path=/bin/true
node run-all.js                  # كل الاختبارات
node run-all.js faq              # الملفات التي في اسمها faq فقط
```

## ماذا يُختبر
| الملف | ماذا يفحص |
|---|---|
| 01-static | صياغة كل ملفات PHP وJS، وعدم تكرار class في نفس العنصر، وعدم وجود كلمات سر في db.php، وتوحيد رقم الإصدار |
| 02-csp | كل الشاشات بدون أي مخالفة لسياسة أمان المحتوى (CSP) وبدون أخطاء JavaScript |
| 03-nav-race | الشاشة البطيئة (الموظفين أو HR) لا ترسم فوق الشاشة الجديدة، وأزرار القائمة الجانبية بعد HR تفتح شاشاتها |
| 04-trades | جدول الصفقات يُبنى تلقائيًا عند حفظ الخطط، وتقرير الإدارة، وإعادة البناء، ومنع غير المصرح لهم |
| 05-faq-bot | المساعد الذكي: الاقتراحات، والرد التلقائي، والتحويل لموظف، والتوقف بعد رد موظف، والصلاحيات |
| 06-polling | الاستعلام المتكيّف: يبطئ عند عدم التفاعل ويعود فورًا مع أول تفاعل |
| 07-price-alerts | تنبيهات السعر المخصّصة: آخر سعر، وشرط ≥ أو ≤، والإيميل والشات والجرس، وعدد مرات التذكير والفرق الزمني |
| 08-trash | سلة المحذوفات: الحذف ينقل العنصر إلى السلة، ثم الاسترجاع لمكانه، ثم الحذف النهائي، مع الصلاحيات |
| 09-features | مراجعة شاملة لكل ميزات الإصدارين 88 و89 في الواجهة، ومنها منحنى إجمالي المحفظة في الرئيسية |
| 10-notifications | الإشعارات تفضل في الرئيسية لحد ما تتقفل، و5 ظاهرين والباقي تمرير، والحذف للسلة والاسترجاع، والنص العربي من غير انعكاس |
| 11-portfolio-consistency | الرئيسية (البطاقة والمنحنى) وشاشة المحفظة والتقارير نفس الأرقام بسعر السوق، وقائمة استثماراتي (فلتر، و5 صفوف، وعرض الكل / إغلاق) |
| 12-alerts-isolation | كل حساب (أدمن / موظف / عميل) يرى إشعاراته فقط من خططه، حتى عند تبديل الحساب في نفس المتصفح |
| 13-markets | أسواق الحسابات: تفعيل سوق، واختيار السوق في التسجيل، وباقات وعملة ودفع سوق الحساب فقط، وتقارير وتوصيات وصفقات لكل سوق |
| 14-studio-order | الاستوديو: تحريك عنصر داخل مجموعته بالأسهم والسحب والحفظ والإرجاع، وخط لكل ثيم، ومفيش أسماء منافسين |
| 15-plan-live-alerts | آخر سعر في شاشات الخطط والربح عليه، وإخفاء الأعمدة، و7 مستويات، ونص إشعارات الخطط وتكرارها، والوقت بتوقيت الجهاز، ومنع ومراجعة الرموز الغلط |
| 16-plan-trash | أي مستخدم (عميل / موظف / أدمن) يحذف خطة DCA أو Grid فتنتقل للسلة، ثم الاسترجاع والحذف النهائي، والاسترجاع لا يكتب فوق خطة جديدة لنفس السهم |
| 17-emergency-ads | الشاشات الطارئة (الصيانة للعملاء فقط، انقطاع النت، السيرفر، التحميل البطيء بالشعار والعد التنازلي) وتعديلها من لوحة التحكم، والدعاية (بانر / منبثق / شريط متحرك / Upsell)، والبحث عن رمز السهم في نموذج الخطة |
